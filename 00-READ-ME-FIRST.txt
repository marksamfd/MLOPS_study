## 🚀 Quick Start (3 Steps)

### Step 1: Setup (Linux/macOS)
```bash
bash setup.sh
```

### Step 1: Setup (Windows)
```cmd
setup.bat
```

### Step 2: Build & Start
```bash
docker-compose build
docker-compose up -d
```

### Step 3: Verify
```bash
curl http://localhost:8000/health
curl http://localhost:5000/health
curl http://localhost:5001/health
```

**All responses should be 200 OK with `"status": "healthy"`**

## 🔄 Complete Workflow

### 1. User Uploads Image
```bash
curl -X POST \
  -F "file=@my_pet.jpg" \
  -F "description=My golden retriever" \
  http://localhost:8000/upload
```

### 2. Web App Processes
- Saves file
- Calls AI service
- Gets generated portrait
- Queues printing order

### 3. Status Tracking
```bash
curl http://localhost:8000/status/{request_id}
```

Shows progression:
- 🟡 Queued (0-1 hour)
- 🟠 Printing (1-2 hours)
- 🟡 Packaging (2-4 hours)
- 🟢 Shipped (4+ hours)
